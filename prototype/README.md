# Прототип 1.1

Историческое описание этапа 1. После подэтапа 2.1 запускать Django из README.md в корне, а не старый server.cjs. Данные теперь из постоянной БД, прежние демо-контакты не загружаются.

Запуск из корня проекта: `node prototype/server.cjs`.
Открыть http://127.0.0.1:8173. Зависимости устанавливать не нужно.

Все 24 контакта синтетические, адреса используют example.com. Реальной БД, сбора, отправки и авторизации нет. Изменения фильтров и выбор строк живут только в памяти вкладки. Архив скрыт по умолчанию.

Доступны поиск, комбинированные фильтры, сортировка каждой колонки, пагинация, выбор строк, CSV-экспорт выбранных строк в текущей выборке либо всей отфильтрованной выборки. Остальные разделы явно отключены до соответствующих подэтапов.

Приёмка: внешний вид на компьютере/телефоне; поиск компании/email; сочетание аудитории и активности; сортировка чисел в обе стороны; пустой результат; сброс; показ архива; переключение страниц; выбор строк и экспорт CSV. Проверить, что демонстрационные статусы и ограничения понятны.

Подэтап 1.2: открыт раздел «Аудитории». Нажатие на сегмент переводит в таблицу с нужными фильтрами, в том числе для исключённых адресов. Нажатие на название клиента открывает карточку: источник, проверка, разрешение, демо-метрики, история и заметки. Заметки сохраняются только в памяти страницы. Закрытие карточки — кнопка или Escape. Проверить возврат в таблицу, сегменты обеих аудиторий и сохранение заметки при повторном открытии карточки.
