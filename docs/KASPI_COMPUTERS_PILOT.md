# Kaspi: пилот компьютеров и комплектующих, 11.11.2026

По запросу заказчика начат сбор публичных контактов продавцов компьютеров и комплектующих. Работы выполняются локально; отправка в GitHub остановлена по предыдущей команде, сервер не обновлялся.

Через обычный браузер выбран Алматы. Открыты категории /shop/c/hardware/ и /shop/c/desktops/, затем по одному товару из процессоров и системных блоков. С первой страницы предложений каждого товара получены по 5 ссылок магазинов. У всех 10 открыта штатная кнопка информации и прочитан опубликованный блок «Контакты». Вход в кабинет продавца, заказы, платные сервисы и обход защит не использовались.

Подтверждены два формата: /shop/m/<ID>/products с merchant-shop-profile и старый /shop/info/merchant/<ID>/reviews с merchant-profile. ID бывает буквенным; обработчик сохраняет его без преобразования в число. Одинаковое имя или телефон не объединяет разные ID. Повтор одного ID объединяет категории и источники обнаружения.

Город в заголовке «в городе Алматы» — выбранный город покупателя, он может отличаться от контактного адреса магазина. В поле города клиента записывается только явно указанный город из адреса контактов; выбранный город хранится отдельным фактом. Если города нет или их несколько, один город не придумывается. Контакты поддержки и футера игнорируются. Телефоны нормализуются и классифицируются по плану нумерации; доступность мессенджеров не проверяется.

Сохранены 10 магазинов и 10 уникальных телефонов. В проверенных блоках email не опубликованы: адреса не угадывались. В локальной БД созданы клиенты kaspi:merchant:<ID>, аудитория «Бизнес → Kaspi» и категории «Компьютеры», «Комплектующие», «Процессоры», «Системные блоки». Полный контактный адрес, ID, категории, город покупателя и ссылки на товары-источники сохранены в истории фактов клиента. Товарные цены и заказы не импортировались. Публикация телефона не считается согласием на рекламу.

В «Сбор данных» добавлена таблица пилота Kaspi с фильтром категории, поиском по названию/ID/городу, телефоном, адресом и ссылкой на магазин. Событие импорта доступно в общем журнале. Это проверенный пилот, **не полный автоматический обход Kaspi**. Охват ограничен 2 товарами / первой страницей предложений / выбранным городом. Утверждения о полном каталоге продавцов нет.

Повторный запуск проверен без дублей. Тесты покрывают оба формата, буквенные ID, отличие города покупателя от адреса, пропуск посторонних контактов, объединение категорий одного продавца и сохранение разных ID при общем телефоне/имени. Скриншот интерфейса хранится локально в docs/screenshots/kaspi-computers-pilot.png. Сырые публичные карточки — data/kaspi, исключены из Git.

Команда повторной проверки: `python manage.py import_kaspi_sample /private/sellers-samples.json`; запись только с `--commit`, максимум 10 карточек. Следующий подэтап после проверки пилота — очередь товаров/страниц предложений с паузой, ограничением частоты и сохранением прогресса, расширение подкатегорий и городов. Исчезновение контакта или отсутствие карточки не должно удалять клиента автоматически.
