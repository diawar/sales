# Уведомления внутри приложения — 12.11.2026

Колокольчик в шапке открывает центр уведомлений. Доступны фильтры по типу и
непрочитанным актуальным сообщениям, пагинация по 25 записей, индивидуальная
отметка прочтения и отметка всей показанной страницы. Прочтение хранится в БД
отдельно для каждого пользователя и сохраняется после перезагрузки страницы.
Можно вернуть отметку «не прочитано». Чужие отметки через API недоступны.

## Источники уведомлений

- Передача рассылки на согласование, одобрение, возврат и снятие одобрения.
- Пауза и автоматическая остановка очереди, сценария или репетиции.
- Ошибка сервера при выполнении действия, уже учитываемая журналом действий.
- Временные и постоянные ошибки имитации очереди.
- Тестовые ошибки доставки/жалобы, заблокированная подготовка и исчерпание
  повторов в репетиции.
- Ошибка состояния источника Goszakup, e-ondiris, Gov.kz, ДФО или Kaspi.

Обычные ошибки заполнения формы и каждый неудачный вход не дублируются в центре.
Необработанные тексты исключений, реквизиты SMTP, пароли, HTML писем и адреса
получателей в уведомления не копируются. Подробности доступны в исходном разделе.

Повторное получение тех же событий не создаёт дубликатов. Ошибки очереди и репетиции
группируются по запуску; при новом событии увеличивается версия карточки, и она снова
считается непрочитанной. Отметка из устаревшего окна не может прочитать новую версию:
сервер возвращает 409. После решения запрос согласования перестаёт требовать внимания;
прежние решения остаются в истории с отметкой «Уже обработано». Они не увеличивают
счётчик актуальных непрочитанных сообщений. Снятие ошибки источника также закрывает
её карточку; повторное возникновение ошибки снова требует внимания.

## Права и переходы

Запрос согласования доступен администратору и отправившему его пользователю.
Решения доступны операционным ролям; ошибки источников и ошибки управления учётными
записями — администратору (собственная ошибка действия может быть видна её автору).
Общие остановки и ошибки имитации видны пользователям с доступом к рабочим данным.
Права пересчитываются при каждом запросе.

Переходы открывают конкретное согласование, очередь или запуск. Для остальных
действий открывается журнал с фильтром объекта. Переход к запуску только показывает
его: имитация, часы и очередь при этом не запускаются. При открытии центра
уведомлений останавливается таймер скрытого раздела сценариев.

Опрос выполняется раз в 30 секунд, пока вкладка активна, и вручную кнопкой «Обновить».
Сам опрос — GET без записи в БД. Это уведомления внутри приложения: разрешение
браузера на push, SMTP, Telegram и другие внешние каналы не используются.

## Установка и хранение

Миграция 0043 добавляет `AppNotification` и `NotificationRead`. Перед применением
сохранена локальная копия SQLite в `data/backups`. Для переноса из существующего
журнала и текущего состояния источников после миграций выполнить:

```text
python manage.py migrate --noinput
python manage.py sync_app_notifications
```

Команда повторяемая, не выполняет сбор, не меняет состояния запусков и не отправляет
письма. После обновления перезапустить приложение и фоновые процессы: обработчики
новых ошибок источников подключаются при старте Django. В локальном приложении
сервер перезапущен; уже существовавшая ошибка Kaspi показана без изменения сборщика.

CSRF, индивидуальное прочтение, версии и дедупликация, снятие актуальности,
группировка ошибок, повторы, фильтры, пагинация, откат транзакций и отсутствие
сетевой отправки/изменений контактов. Пройдены Django check, проверка миграций,
синтаксиса JavaScript и git diff --check.

В браузере проверены колокольчик, переход к имитации №4 и согласованию рассылки №6,
появление нового запроса, сохранение прочтения после перезагрузки страницы,
возврат отметки «не прочитано», настольный вид и ширина 320 px без горизонтальной
прокрутки. В рабочей локальной БД тестовый черновик №6 без получателей оставлен
на проверке, версия согласования 5. Очередей нет. Изменены только уведомления,
собственные отметки чтения и тестовое согласование; импорта клиентов не было.

Реальная отправка выключена. Коммит и публикация не выполнялись. Подэтап завершён
для проверки пользователем; следующий этап не начинать без его запроса.
