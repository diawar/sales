# Клиенты и рассылки

Локальное приложение для сбора контактов, аудиторий и подготовки рассылок. Django 5.2, Python 3.11+, SQLite или PostgreSQL. Интерфейс находится в prototype/dist.

## Состояние

Подключены сборщики Goszakup, e-ondiris, Gov.kz и ДФО, аудитории, фильтры, карточки клиентов, история источников и проверка email. Проверка DNS не подтверждает существование ящика. Отправка сообщений пока не подключена. Kaspi ещё не подключён.

Over-shop.kz: подготовлены все ID зарегистрированных клиентов, выполнен пилот импорта 8 кандидатов с сегментами покупок. Полная загрузка и постоянная синхронизация ещё не выполнены. Классические подписки сайта и Email-маркетинг — разные источники статусов; регистрация и покупка не подтверждают согласие на рекламу.

## Локальный запуск

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python manage.py migrate
.venv/Scripts/python manage.py runserver 127.0.0.1:8173 --noreload
```

База: data/contacts.sqlite3. Не удалять data/ при обновлении. POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_HOST, POSTGRES_PORT включают PostgreSQL, но сами не переносят данные.

Отдельные процессы: `manage.py collect_contacts`, `collect_producers`, `collect_gov`, `collect_dfo`, `check_emails`. Управление паузой — в интерфейсе. Проверки: `manage.py test contacts`.

Приватная БД, выгрузки, скриншоты, окружение и исторические рабочие отчёты не публикуются. Примеры в fixtures — демонстрационные. Для Over-shop нужны собственные разрешённые выгрузки; пути по умолчанию в скриптах относятся к локальному окружению и должны быть заменены аргументами нужных файлов.

## Развёртывание

Задание агенту: [docs/DEPLOYMENT_AGENT_TASK.md](docs/DEPLOYMENT_AGENT_TASK.md). Создать и заполнить серверную БД, развернуть sales.overclockers.kz и добавить «Рассылки» в меню p1.overclockers.kz.

**Текущая версия не имеет авторизации и предназначена для localhost.** До публикации необходимо защитить приложение и все API, настроить production-сервер, HTTPS, секреты и резервные копии. Реальные рассылки не запускать при развёртывании.
